# HR ANALYTICS DASHBOARD

## Project Overview
An HR Analytics Dashboard created using Microsoft Power BI to analyze employee data and understand workforce attrition patterns.

## Key Performance Indicators (KPIs)
- Total Employees: 1.47K
- Total Attrition: 238
- Attrition Rate: 16.2
- Average Age: 37
- Average Years at Company: 7.0
- Average Salary: 6.5K

## Dashboard Features
- Employee attrition analysis by gender.
- Attrition analysis by education field.
- Age-wise attrition analysis.
- Salary slab analysis.
- Attrition by years at company.
- Job role-wise attrition analysis.

## Tools & Technologies
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Business Intelligence
